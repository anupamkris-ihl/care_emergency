Migration 0010_emergency_complaint_arrival new

dependencies = [('care_emergency', '0009_quick_registration')]
operations = [
    AddField('emergencyencounter', 'chief_complaint', CharField(blank=True, default='', max_length=40)),
    AddField('emergencyencounter', 'mode_of_arrival', CharField(blank=True, default='', max_length=40)),

It was first created as 0008, then renumbered to 0010 because a teammate's v0.7.0 and v0.8.0 already use 0008_nok_title_permanent_country and 0009_quick_registration. Both columns have a default, so existing rows get empty strings and nothing else is touched.

Query to see emergency patients

SELECT p.name, p.gender, e.triage, e.chief_complaint, e.mode_of_arrival,
       e.is_medico_legal, e.mlc_number, e.brought_by_name, e.brought_by_phone,
       e.is_unidentified, e.created_date
FROM care_emergency_emergencyencounter e
JOIN emr_patient p ON p.id = e.patient_id
ORDER BY e.created_date DESC;

Screens

  • Popup "Which Emergency Entry?": one dropdown with Emergency / Casualty (Quick Registration), Unknown / Unidentified, and Code Orange (disabled), then Continue. Full-width button on phones.
  • Emergency Quick Registration: title + first/middle/last name, gender, age, contact (attendant, optional), chief complaint (required), mode of arrival, brought by, Medical Legal Case checkbox, triage. Patient Cannot Be Identified switches to the unknown screen and keeps what was typed.
  • Unknown / Unidentified Registration: gender, estimated age, brought by or from, distinguishing marks, Medical Legal Case checkbox, triage. The old second "accompanying person" step was removed.
  • Medical Legal Case checkbox (both screens): unticked by default; ticking shows MLC nature, auto MLC number and police station, which then become required.
  • Setup boxes: if the facility has no unit code or no emergency desk number, the screen asks for it (facility admins only).
  • Create And Print Wrist Band: saves, then shows a wristband (triage colour, name, UHID or UNK number, sex/age, MLC number, time, facility) and opens the print dialog. Done returns to the dashboard.

7. Deploy steps

  1. Commit and push the plug, then tag it: 
    cd "D:/care backend/care-emergency/care_emergency"
git add -A
git commit -m "feat: emergency chief complaint, mode of arrival, optional brought-by name (v0.9.0)"
git push origin main
git tag v0.9.0
git push origin v0.9.0
  2. In ihl-hims-backend/plug_config.py, change version="@v0.7.0" to version="@v0.9.0", then commit and push. Do this after the tag exists.
  3. After the server redeploys, run python manage.py migrate care_emergency (applies 0008, 0009, 0010).
  4. Set a unit code and emergency desk number for each facility (from the emergency screen or desk registration).
The frontend already sends the new fields. Emergency registration on a server still running plug v0.7.0 will fail until steps 1–3 are done.
