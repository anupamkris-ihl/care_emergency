Backend

Database

No new tables. International patients use the existing care_emergency_patientregistration table (one row per patient, linked to Care's emr_patient). One column was added by migration 0012_international_tariff_consent.

ColumnTypeInternational use
registration_typevarchar(10)INT, or NRI
nationality_categoryvarchar(20)Foreign, Refugee, NRI
nationalityvarchar(60)Country of origin
identity_card_type / identity_number_last4varchar(20) / varchar(4)passport or unhcr_card; last 4 characters only
passport_numbervarchar(15)Full passport number
visa_type / visa_expiryvarchar(30) / dateVisa status and validity
address_in_indiavarchar(300)Hotel, guest house or relative
alternate_phone_numbervarchar(16)Indian +91 number
international_tariff_consentboolean · NEWConsent 7
guardian_name / guardian_relationshipvarcharChild's kin as guardian (S/O, D/O, Ward of)

Documents are rows in care_emergency_patientdocument (category passport / visa / government_id / payer_card), with the file in S3 storage. The UHID is a row in Care's emr_patientidentifier.

Testing

Run locally

  1. Start Docker Desktop, then: docker start care-silo
  2. Backend: & "D:\care backend\start-care-backend.ps1" (API on http://localhost:9000)
  3. Frontend: cd "D:\care backend\ihl-frontend\hmis_fe"; npx next dev -p 3000
  4. Open http://localhost:3000, sign in, search a +44 number → Add Patient → International
  5. If a teammate added migrations: . "D:\care backend\care-env.ps1"; .\.venv\Scripts\python.exe manage.py migrate
